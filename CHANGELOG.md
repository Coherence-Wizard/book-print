# Changelog

## 0.0.2 — review candidate

- Coherence Wizard attribution and the community-compatible `book-print` ID.
- Searchable Obsidian settings, standard setting groups, and consistent UI text.
- Explicit migration from the earlier private installation, preserving original data.
- Validation of saved data so a malformed project cannot silently reset the project list.
- Cleanup of hidden PDF-rendering windows and child dialogs on close/unload; no checkout opens after the book window closes.
- Typed desktop imports and API boundaries; uploaded-PDF previews restricted to the configured service's file endpoint.
- Standalone client source package, reproducible build, review checks, privacy disclosures, and embedded third-party license notices.
- Book Print Source-Available License 1.0 by Coherence Wizard, with restrictions on commercial code reuse and public modified distribution; the license is included in the installed bundle.

## 0.0.1 — preserved private baseline

The existing working plugin was archived as 0.0.1 by Coherence Wizard before review changes. This preserves the functionality previously labeled 2.5.0, with only release metadata renumbered. It was not submitted to the community directory.
