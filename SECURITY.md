# Security reports

Report potential vulnerabilities privately to josephrastovich@gmail.com. Include reproduction steps and the plugin version. Do not attach payment credentials, manuscripts, shipping addresses, private file links, or order-access tokens to public issues. If sensitive data is necessary to reproduce a problem, arrange a private exchange first.

The review candidate uses local sandboxed Electron rendering and a separate hosted ordering service. A passing linter is not a security guarantee; report unexpected network activity, unsafe rendering, or order-access issues promptly.
